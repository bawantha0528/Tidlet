## Shell and lifecycle

| Contract | Documented fact and implementation consequence | Official source |
|---|---|---|
| Window styles | WS_EX_NOACTIVATE prevents normal activation; WS_EX_TOOLWINDOW excludes taskbar/Alt+Tab. Use these for the ambient island; settings/confirmations have a normal accessible window. | Layered surface size | Layered updates can update the whole surface; keep the HWND close to actual content. Do not allocate a transparent screen-sized overlay. | [UpdateLayeredWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-updatelayeredwindow) |

## Approved native renderer — official sources checked 29 October 2026

User approved the Win32 renderer exception. No package or driver is used. WPF legacy code is isolated behind its explicit entry path. The native probe actually reported zero loaded PresentationFramework/PresentationCore/WindowsBase assemblies. Later full-shell verification is separate.

- Window creation/class ABI: https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerclassexw ; https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-wndclassexw ; https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-createwindowexw . Register class once per owned instance; root callback delegate; unregister after destroying owned window. Reverse callbacks catch errors instead of unwinding across native code.
- Native loop: https://learn.microsoft.com/en-us/windows/win32/winmsg/using-messages-and-message-queues ; https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-msg . GetMessage returns -1 for error, 0 for quit, positive for a message. Preserve pointer-sized WPARAM/LPARAM. MSG includes the documented reserved lPrivate field; installed SDK hides it on Windows, but the larger documented buffer is safe and field offsets match. WNDCLASSEX is 80 bytes on x64, 48 on x86; documented MSG buffer 48/32.
- Module handle: https://learn.microsoft.com/en-us/windows/win32/api/libloaderapi/nf-libloaderapi-getmodulehandlew . Null name identifies this executable; borrowed handle is not freed.
- Visibility: https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-showwindow . SW_SHOWNOACTIVATE=4; first ShowWindow can honor STARTUPINFO instead. Explicitly repeat if WS_VISIBLE remained false. Its return value describes previous visibility, not success/failure.
- Timer: https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-settimer ; https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-killtimer . WM_TIMER uses native-size ID; zero SetTimer result is failure. KillTimer does not remove queued ticks, so active timer membership and host state guard dispatch.
- Layered surface: https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-updatelayeredwindow ; https://learn.microsoft.com/en-us/windows/win32/api/wingdi/ns-wingdi-blendfunction . ULW_ALPHA=2, AC_SRC_OVER=0, SourceConstantAlpha=255, AC_SRC_ALPHA=1; BGRA channels are premultiplied. UpdateLayeredWindow copies the whole surface; keep bounds small. BLENDFUNCTION is four packed bytes.
- DIB: https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-createdibsection ; https://learn.microsoft.com/en-us/windows/win32/api/wingdi/ns-wingdi-bitmapinfoheader . Negative height means top-down BI_RGB. 32-bit pixels are DWORD-aligned; checked width × height has a 4-million-pixel allocation ceiling. Header size 40; BITMAPINFO with first RGBQUAD 44. Scope unsafe spans to the allocated DIB lifetime.
- Drawing resource ownership: https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-createcompatibledc ; https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-selectobject ; https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-deleteobject ; https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-deletedc . Restore previously selected objects before deletion; release owned bitmap/font/DC on failure and shutdown.
- Text mask: https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-createfontw ; https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-drawtextw ; https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-settextcolor ; https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-setbkcolor ; https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-setbkmode ; https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-gdiflush . Negative font height selects glyph height; ANTIALIASED_QUALITY=4 avoids subpixel color masks. Flush before reading GDI-written DIB pixels. Empty strings are skipped; DrawText zero and GDI setup/flush failures are surfaced. Actual rendered probe BMP was inspected.
