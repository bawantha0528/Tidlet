Active stack returns to C#/.NET 8 + WPF + verified Win32 interop. Stop after R2 or immediately on a failed resource gate. No third-party icons: use installed Windows font icons; Lucide assets/code are legacy and must not enter the active build.

Retire tests of removed presentation explicitly, never call those checks passing. Update engineering agreement and credit. Copy all six supplied references into ignored docs/reference. Create a minimal WPF bar feasibility fixture, no AppBar reservation, startup registration, outbound request, music or process action. ## R1 execution detail after approved feasibility baseline

Implement portable BarSettings, item bounds and physical-adapter delta policy; Windows owns monitor/work-area enumeration, AppBar lifecycle, native tray/context menu and foreground/fullscreen events; Shell owns WPF HwndSource and accessible DrawingVisual items. Default Overlay/Top/Center/Primary, 24 DIP, 3-second polling. JSON bar settings are local and independently versioned, preserving historical settings. Use full-width translucent WPF surface with solid/high-contrast fallback; no undocumented acrylic calls. Unavailable battery hides its item, failed available sensors show explanation. Network uses physical GetIfTable2 rows and per-LUID monotonic deltas; exclude virtual/filter/tunnel and reset on adapter changes. Native menu avoids initializing WPF control templates; dashboard/full settings are clearly deferred to R4 rather than simulated.

AppBar registration/remove are paired, with ABN_POSCHANGED renegotiation and primary/secondary top-taskbar detection. Recovery journals carry HWND/PID/start identity; remove only a recorded dead/non-reused window handle, never manipulate SPI_SETWORKAREA or another process. Verify actual shell recovery using an owned bounded fixture before claiming crash recovery; if shell behavior is unverified, report it explicitly. Hidden/fullscreen metrics pause; foreground events plus bounded low-frequency notification-state checks resume. Reserve release on hide and shutdown. No unrelated process termination, settings or runtime installation.

Before R2: build/test, native structure checks on both architectures, normal/Reserve/hidden and settings variants in owned bounded runs, then a full 300-second bar trial including tray/network/battery. Preserve raw data and report physical hardware gaps. Only proceed to popup implementation after the resource gate passes.
