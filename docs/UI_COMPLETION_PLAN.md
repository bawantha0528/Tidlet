## R3 implementation detail after the approved common 90 MB gate

Local address data must match the measured adapter Guid. ICMP is an explicit opt-in and requires at least three samples; public-IP and per-process network remain off. Battery: system percent/AC/charging plus only valid reported mWh capacities and cycles; reject unknown sentinels/relative units, clamp valid health to 100%, never label remaining discharge life as charging completion. Native query boundaries are mocked in tests; no setting-changing action is run.

Disk: verified PhysicalDisk PDH read/write and idle counters, per-instance activity without adding _Total twice, separate fixed-volume capacity rows from DriveInfo (never infer a physical-disk/volume relationship). Any unverified mapping stays TODO(verify)/unavailable. Probe native layout on x86/x64 and handle missing/denied counters without a crash. No package or driver.
